# CodePulse AI — Multi-Language Code Quality Scanner

A code quality and security scanning tool built as a personal/hackathon project to explore AI-assisted software development. The project analyzes source code across multiple languages to surface code quality issues automatically.

## About This Project

This was built largely through AI-assisted development (prompting and iterating with Claude) as a way to explore what's possible with AI-driven coding workflows. It's a personal project — treat it as a working prototype and a learning exercise in directing AI-assisted builds.
## What It Does

- Scans source code for quality and security issues across multiple languages (Python, JavaScript)
- Flags common issues like unused imports, high cyclomatic complexity, missing documentation, and basic security anti-patterns

## What I Actually Built / Configured

- Directed the AI-assisted development of the core scanning logic and iterated on its output
- Reviewed and tested the scanner against sample code to validate its output

## Tech Stack

- **Backend**: Python (Flask)
