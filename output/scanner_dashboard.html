Creative Path G: Personality Profiler

🤔

Codebase Personality Profiler

Transform code metrics into memorable, actionable personality archetypes

Your codebase is more than numbers. Discover its character with the Personality Profiler.

🎯 How It Works

The Personality Profiler analyzes your codebase across six dimensions and assigns it one of six memorable archetypes:

  • 🤔 The Anxious Overthinker — High complexity + extensive logging
  • 🚀 The Reckless Optimist — Security findings + low error handling
  • 📋 The Copy-Paste Artist — High code duplication
  • 🔀 The Chaotic Connector — Circular dependencies + high coupling
  • ✅ The Cautious Perfectionist — High quality + excellent docs
  • 🤐 The Quiet Newcomer — Small codebase with neutral scores

📋 Generate Your Personality Card

Run the scanner with the --personality flag to get personality insights:

python -m scanner ./your-project \ --personality \ --quality-score \ --code-smells \ --doc-coverage \ --security \ --personality-html output/personality_card.html

The personality card will be generated as a beautiful, interactive HTML file that you can share with your team.

✨ Features

  • Rule-based personality matching (no AI/ML required)
  • 6 memorable archetypes with emojis and taglines
  • Trait scores across 6 dimensions (0-100 scale)
  • Evidence citations with supporting metrics
  • Strengths and blind spots analysis
  • 3 actionable relationship tips per archetype
  • Beautiful, responsive HTML card
  • Markdown section for integration into reports

📚 Integration with CAQI & Reports

The Personality Profiler works seamlessly with the Code Air Quality Index (CAQI) and all reporting formats:

  • JSON Output: Complete personality profile in structured format
  • Markdown: Personality section for reports and documentation
  • HTML Card: Standalone personality card for presentations
  • Dashboard: Personality insights alongside other metrics

Creative Path H: Inheritance Letter

📬

Inheritance Letter

Your codebase writes you a confession letter confessing its issues, warning about dangers, and guiding where to start.

Code metrics are boring. First-person confessions are unforgettable.

💌 How It Works

The Inheritance Letter generates three distinct tones based on code health, creating a narrative that helps developers understand the codebase at a human level:

  • 🔴 Apologetic (Red) — High security debt or poor quality. "I left an API key in insecure.py. I'm sorry."
  • 🟡 Cautious (Amber) — Moderate issues. "I'm fairly complex in places. Let's talk about refactoring."
  • 🟢 Confident (Green) — Clean, well-maintained code. "I'm well-documented and maintainable. Ready to contribute?"

📝 Letter Structure

Each letter contains 6 sections that guide the next maintainer:

  1. What I'm Proud Of — Top 3 files with highest quality
  2. What I'm Not Proud Of — Bottom 3 files with most issues
  3. Secrets I've Been Keeping — First-person confessions of security findings
  4. Rooms You Should Avoid First — Top 3 complex functions to skip initially
  5. Where to Start Instead — Safe, low-complexity entry points
  6. How to Survive Your First Week — Tone-specific actionable tips

🚀 Generate Your Letter

Run the scanner with the --inheritance-letter flag:

python -m scanner ./your-project \ --inheritance-letter \ --security \ --quality-score \ --code-smells \ --doc-coverage \ --inheritance-html output/letter.html

The inheritance letter will be generated as a beautiful, tone-matched HTML file ready for browser viewing or printing to PDF.

✨ Features

  • 3 distinct tones (apologetic, cautious, confident) based on code health
  • First-person narrative from the codebase perspective
  • 6 sections guiding new developers where to start
  • Tone-matched color scheme (red/amber/green) for visual clarity
  • Self-contained HTML (email-ready, offline-ready)
  • Professional styling with responsive design
  • Print-friendly for team presentations
  • Large fonts (18px+) readable from 10 feet away

📚 Example Letters

View example letters generated from real code patterns:

  • 🔴 Apologetic Example — Security issues & low quality
  • 🟡 Cautious Example — Moderate issues & medium quality
  • 🟢 Confident Example — Clean code & high quality

📊 Integration with Personality & CAQI

The Inheritance Letter works seamlessly with the Personality Profiler and CAQI. Generate all three together for a complete picture:

python -m scanner ./your-project \ --personality --personality-html output/personality.html \ --inheritance-letter --inheritance-html output/letter.html \ --caqi --caqi-html output/caqi.html \ --security --quality-score --code-smells --doc-coverage \ --output output/report.json

This creates three complementary outputs: Personality (archetype), Inheritance Letter (narrative), and CAQI (health score).
